# Customer Analytics Dashboard

## Project Overview
An interactive dashboard for analyzing e-commerce sales,
customer segments, product performance, and profitability.

## Tools Used
- Python
- Pandas
- Plotly
- Streamlit
- Jupyter Notebook

## Features
- Interactive filters
- KPI cards
- Sales and profit charts
- Customer analysis
- Product analysis
- Dynamic business insights
- Filtered CSV download

## How to Run

Install the required packages:

pip install -r requirements.txt

Run the dashboard:

streamlit run ecommerce_dashboard.py
